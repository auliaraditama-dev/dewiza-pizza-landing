# Operasional Website Dewiza Pizza & Cafe

## Sebelum Cafe Buka

Periksa:
- status menu tersedia/habis;
- harga menu;
- promo aktif;
- voucher aktif;
- jam operasional;
- nomor WhatsApp pemesanan;
- layanan Dine In/Take Away/Delivery yang sedang tersedia;
- pengumuman khusus hari tersebut.

## Ketika Cafe Beroperasi

Website dapat digunakan pelanggan untuk:
1. melihat menu;
2. mencari dan memfilter menu;
3. menyimpan favorit;
4. memasukkan item ke keranjang;
5. memilih jenis pesanan;
6. menggunakan voucher jika ada;
7. mengisi detail order;
8. mengirim ringkasan pesanan ke WhatsApp cafe.

## Jika Menu Habis

Jangan menghapus menu jika hanya habis sementara. Ubah status menjadi tidak tersedia agar:
- pelanggan masih dapat melihat menu;
- pelanggan mengetahui menu tersebut sedang tidak dapat dipesan;
- menu tidak dapat ditambahkan ke keranjang.

## Jika Harga Berubah

Perbarui harga pada data menu sebelum cafe mulai menerima pesanan dengan harga baru.

## Jika Ada Promo atau Voucher

Pastikan:
- nilai diskon benar;
- minimum transaksi benar;
- maksimum diskon sesuai;
- masa berlaku sesuai;
- status aktif sudah benar.

## Jika Cafe Tutup Sementara

Cafe dapat:
- mengubah jam operasional;
- menampilkan pengumuman;
- mengaktifkan pembatasan order di luar jam buka;
- tetap menerima scheduled order jika layanan tersebut digunakan.

## Delivery

Pastikan pelanggan diminta mengisi alamat lengkap jika layanan Delivery aktif.

Biaya delivery dapat ditambahkan pada jenis pesanan jika cafe menggunakan biaya tetap.

## Dine In

Detail jenis pesanan dapat digunakan untuk meminta nomor meja atau informasi lain yang dibutuhkan cafe.

## Take Away

Detail dapat digunakan untuk nama pengambil atau informasi tambahan sesuai kebutuhan cafe.

## PWA pada Perangkat Cafe

Website dapat dipasang sebagai aplikasi pada perangkat cafe agar akses lebih cepat.

Ketika versi website baru tersedia, pengguna dapat menekan tombol Perbarui pada notifikasi aplikasi.

## Ketika Internet Bermasalah

Website dapat menampilkan katalog terakhir yang pernah berhasil dimuat pada perangkat tersebut. Status offline akan terlihat pada tampilan.

Pesanan WhatsApp tetap memerlukan koneksi internet untuk dikirim.

## Data Pelanggan

Website menyimpan keranjang, favorit, riwayat menu, dan draft pesanan pada perangkat pelanggan untuk kenyamanan penggunaan.

Hindari memasukkan informasi pelanggan ke dalam data menu atau data publik toko.

## Setelah Perubahan Data

Setelah menu, harga, promo, voucher, jam operasional, atau informasi toko diperbarui, lakukan pengecekan tampilan pada:
- halaman beranda;
- halaman menu;
- keranjang;
- checkout WhatsApp;
- tampilan mobile.
