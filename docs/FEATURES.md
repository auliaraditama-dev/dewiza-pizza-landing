# Feature Matrix v7

## Catalog
- JSON data source tanpa fallback produk.
- Validasi item dan ID unik.
- Search realtime.
- Autocomplete/search suggestion dengan keyboard.
- Filter kategori/favorite.
- Filter tersedia saja.
- Filter harga minimum/maksimum.
- Sorting dan pagination.
- URL state/deep-link/share.
- Quick view.
- Recently viewed + clear history.
- Metadata produk opsional: badge, tags, allergens, calories, spicyLevel, featured.

## Cart & Order
- Cart/favorite persistence.
- Quantity limit.
- Order draft persistence.
- Voucher persistence + min order/max discount/expiry.
- Fee per order type.
- Minimum order configurable.
- Nama/catatan/detail order.
- Scheduled order configurable dengan lead-time, days-ahead, dan validasi jam operasional.
- Copy/share order summary.
- Referensi order otomatis.
- WhatsApp checkout validation.
- Optional block ordering outside opening hours.

## Business UX
- Dynamic open/closed indicator.
- Machine-readable opening hours.
- Configurable announcement banner.
- Dark/light theme.
- Responsive desktop/tablet/mobile.
- Fixed mobile bottom navigation.
- Skeleton/empty/retry/offline/toast states.

## PWA & Offline
- Install prompt.
- Versioned service worker cache.
- Update notification.
- Network-first JSON.
- Last catalog localStorage fallback + cache timestamp.
- Image runtime cache with entry limit.
- Offline fallback.
- PWA shortcuts.

## SEO & Accessibility
- Canonical, Open Graph, Twitter Card.
- Restaurant/Menu/MenuSection/MenuItem structured data.
- OpeningHoursSpecification, nutrition, keywords when data exists.
- Dynamic title/description for category/item.
- 404 GitHub Pages, robots, sitemap.
- Skip link, aria-live, aria-current.
- Focus trap/restore, Escape close.
- Search combobox/listbox ARIA.
- Reduced motion and focus-visible.
