# Fitur Dewiza Pizza & Cafe

## Pengalaman Pelanggan

### Beranda
- Identitas dan informasi utama cafe.
- Status buka/tutup.
- Menu pilihan.
- Promo dan pengumuman jika tersedia.
- Ulasan pelanggan jika tersedia.
- Alamat, kontak, sosial media, dan lokasi.

### Menu
- Pencarian cepat.
- Saran pencarian.
- Filter kategori.
- Filter tersedia saja.
- Filter harga.
- Urutan nama/harga.
- Pagination.
- Detail menu.
- Share/copy link produk.
- Informasi tag, alergen, kalori, pedas, badge, dan menu unggulan jika tersedia.

### Favorit
- Menyimpan menu favorit pada perangkat pelanggan.
- Filter khusus favorit.

### Riwayat Menu
- Menampilkan menu yang terakhir dilihat.
- Riwayat dapat dihapus pelanggan.

### Keranjang
- Tambah, kurangi, dan hapus item.
- Batas quantity per item.
- Subtotal, voucher, biaya, total.
- Ringkasan pesanan dapat disalin/dibagikan.
- Keranjang tetap tersimpan pada perangkat pelanggan.

### Pemesanan
- Dine In, Take Away, Delivery sesuai layanan toko.
- Nama pelanggan dan catatan pesanan jika digunakan.
- Detail order seperti alamat atau nomor meja.
- Jadwal pesanan jika diaktifkan.
- Minimum order jika ditetapkan.
- Validasi jam operasional jika diaktifkan.
- Checkout langsung ke WhatsApp toko.

### Voucher
- Potongan nominal/persentase.
- Minimum transaksi.
- Maksimum diskon.
- Masa berlaku.
- Status aktif/nonaktif.

## Operasional Cafe

### Data Menu
Cafe dapat mengatur:
- nama;
- harga;
- kategori;
- deskripsi;
- gambar;
- tersedia/habis;
- badge;
- tag;
- alergen;
- kalori;
- tingkat pedas;
- unggulan.

### Informasi Toko
Cafe dapat mengatur:
- nama usaha;
- logo;
- alamat;
- WhatsApp;
- Instagram;
- map;
- jam buka;
- jenis pesanan;
- biaya layanan;
- promo;
- voucher;
- ulasan;
- pengumuman.

### Status Operasional
- Status buka/tutup otomatis.
- Pemesanan dapat dibatasi saat cafe tutup.
- Jadwal pesanan dapat digunakan untuk pesanan mendatang.

### PWA dan Offline
- Website dapat dipasang sebagai aplikasi.
- Shortcut Menu dan Keranjang.
- Update website diberitahukan kepada pengguna.
- Katalog terakhir dapat tersedia saat koneksi terputus.
- Status offline ditampilkan dengan jelas.

## Tampilan
- Desktop/tablet header ringkas.
- Mobile bottom navigation fixed.
- Theme, Install, dan Cart tetap di header mobile.
- Dark/light mode.
- Skeleton, empty state, retry, toast, dan back-to-top.
- Layout aman untuk layar kecil dan safe-area perangkat modern.

## Aksesibilitas
- Navigasi keyboard.
- Fokus yang jelas.
- Focus trap pada cart/modal.
- Escape untuk menutup panel.
- Dukungan pembaca layar.
- Reduced motion.
